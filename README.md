# Розничная торговля продуктами в сети магазинов у дома

Проект учебной практики (РТУ МИРЭА, ИИТ, кафедра ИиППО, осенний семестр 2026/2027).

**Студент:** Лугинец Анна Павловна, группа ИКБО-15-24
**Руководитель практики от кафедры:** Рачков А.В.

## Цель проекта

Исследование предметной области розничной торговли продуктами в сети магазинов у дома,
построение модели основного бизнес-процесса и разработка программного решения
для автоматизации его операций.

## Структура репозитория

```
convenience-retail-practice/
├── src/retail/     # исходный код на Python
├── tests/          # тесты
├── data/           # исходные данные
├── docs/           # материалы отчёта по этапам
├── requirements.txt
└── README.md
```

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m src.retail.main
```

## Порядок работы с Git

- `main` — стабильная версия проекта;
- новые части задания разрабатываются в ветках `feature/...`;
- изменения вливаются в `main` через pull request после рецензирования.
